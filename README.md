# Task Tracker

A lightweight, clean, and responsive **Task Tracker** web application built using native web technologies. This application allows users to efficiently manage, organize, and track their daily tasks or to-do lists directly from their web browser.

## 🚀 Features

* **Task Management**: Easily add, complete, and delete tasks.
* **Persistent Storage**: Uses browser `LocalStorage` so your tasks remain saved even after refreshing the page. (Optional/Recommended implementation in `script.js`)
* **Responsive Design**: Clean and modern user interface that works seamlessly across desktop, tablet, and mobile screens.
## 📁 Project Structure

The repository consists of the following core files:

```text
task-tracker/
│
├── .gitignore   # Configured to ignore unnecessary system or environment files
├── index.html   # The structural skeleton and layout of the application
├── style.css    # Custom UI styling, layouts, and interactive animations
└── script.js    # Core application logic, task handling, and DOM manipulation
```

## 🛠️ Built With

* **HTML5**: Semantic elements for structure.
* **CSS3**: Modern layouts (Flexbox/Grid) and custom styling.
* **JavaScript (ES6+)**: Dynamic DOM updates and logic handling.

## 🏁 Getting Started

To get a local copy up and running, follow these simple steps:

### Installation & Running
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project directory:
   ```bash
   cd task-tracker
   ```
3. Open the application:
   * Simply double-click the `index.html` file to open it in your default browser.
   * *Alternatively*, if using VS Code, right-click `index.html` and select **"Open with Live Server"**.
